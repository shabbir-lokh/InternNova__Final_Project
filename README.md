
# TaskFlow – Task Management System

A responsive task management web application built using
HTML, CSS, and JavaScript.

## Features

- Create, edit, and delete tasks
- Mark tasks as completed or pending
- Set priority levels: High, Medium, and Low
- Add task descriptions and due dates
- Search tasks by title or description
- Filter tasks by status and priority
- View dashboard statistics and progress
- Highlight overdue tasks
- Save tasks in browser localStorage
- Responsive desktop, tablet, and mobile design

## Technologies Used

- HTML5: Semantic structure and forms
- CSS3: Box model, Flexbox, Grid, media queries
- JavaScript: Functions, arrays, objects, DOM manipulation
- Browser localStorage: Persistent task storage
- Git and GitHub: Version control

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Add and manage your tasks.

No backend or package installation is required.
